## 컬렉션 프레임워크
> 여러 개의 데이터(객체)를 효과적으로 관리하기 위해 자바에서 제공하는 클래스들의 묶음 크게 List, Set, Map 인터페이스로 분류

## set(인덱스, 값)
> 해당 위치 수정 중복 불가 순서 없음 Set은 인덱스가 없기 때문에, List처럼 get()을 사용하여 요소를 꺼낼 수 없음 따라서 전체 요소를 대상으로 연속 처리를 하고 싶을 때는 이 방법을 사용
1. toArray() Set을 배열로 바꿔서 반복
2. iterator() 반복자를 사용하여 연속처리 iterator는 어떤 컬렉션이든 동일한 방식으로 순회할 수 있게 해주는 반복자 객체

## LinkedList
> 각 요소가 앞뒤 요소를 링크로 연결 추가/삭제 링크만 수정하면 되므로 중간 삽입/삭제가 빠름 조회 처음부터 순서대로 찾아야 하므로 느림

## stack
> 후입선출(LIFO) 마지막에 넣은 것이 먼저 나옴 peek 맨 위의 값을 확인(제거는 하지 않음) pop 맨 위의 값을 꺼내고 제거

## Queue
> 선입선출(FIFO) 먼저 넣은 것이 먼저 나옴 Queue는 인터페이스이므로 LinkedList로 구현체 생성

## hashSet
> 순서없음+중복불가

## LinkedHashSet
> 중복 불가 + 순서를 유지

## TreeSet
> 중복불가 + 자동 오름차순 정렬 조건 : 요소가 Comparable을 구현해야 자동 정렬 가능 String, Integer 등 기본 Wrapper 클래스는 이미 Comparable 구현 완료되어 있음

## Map 인터페이스
> key와 value를 하나의 쌍(Entry)으로 묶어서 관리 key는 중복 저장을 허용하지 않음 value는 중복 저장을 허용함
1. KeySet() 키 전체를 Set으로 받아서 순회
2. values() 값만 꺼낼 때
3. entrySet() 키+값 을 한번에 Map.Entry 객체로 꺼냄

## properties
> HashMap을 상속받은 특수 map key와 value 모두 반드시 String 주 용도 : 프로그램 설정 정보(DB 연결정보, 환경설정 값) 관리
