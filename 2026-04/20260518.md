## connection
> 자바 어플리케이션과 db사이에 만들어지는 연결 통로 DriverManager를 통해 db접속 정보를 전달하면 Connection 객체를 얻을 수 있음


## 사용할 jdbc driver 클래스 로딩
> Class.forName("com.mysql.cj.jdbc.Driver"); connection = DriverManager.getConnection("jdbc:mysql://localhost/employeedb", "ohgiraffers", "ohgiraffers"); con = DriverManager.getConnection(url, prop);

## properties 세팅
* driver=com.mysql.cj.jdbc.Driver
url=jdbc:mysql://localhost/employeedb
user=ohgiraffers
password=ohgiraffers

## db 연결 예시
1. 커넥션 객체 생성
* Connection con = JDBCTemplate.getConnection();
2. 쿼리를 운반하고 결과를 반환하는 객체
* Statement statement = null;
3. select 결과집합을 받아올 용도의 객체
* ResultSet resultSet = null;
4. connection을 이용하여 statement(쿼리를 싣고 다닐 객체) 생성
* statement = con.createStatement();
resultSet = statement.executeQuery("SELECT menu_name, menu_price FROM TBL_MENU");
5. next() : resultset의 다음 행을 보며 행이 존재하면 true, 존재하지 않으면 false 반환
* while(resultSet.next()) {}
