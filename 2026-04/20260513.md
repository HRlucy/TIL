## Consumer<T>
> T를 받아 소비(처리)만 하고 반환 없음
* Consumer<String> printName = name -> System.out.println("환영합니다 " + name + "님");

## 객체를 만드는 람다식을 줄이는 문법
1. 정적 메소드 참조
* Function<String, Integer> parseInt = s -> Integer.parseInt(s);
2. 특정 객체의 인스턴스 메소드 참조 객체참조변수::인스턴스메소드이름
* Consumer<String> println = str -> System.out.println(str);
3. forEach와 메소드 참조
* List<String> subjects = Arrays.asList("java", "mysql", "jdbc", "css");
4. 불특정 다수 객체의 인스턴스 메소드 참조
* BiFunction<String, String, Boolean> equals = (s1, s2) -> s1.equals(s2);
* BiFunction<String, String, Boolean> ref_equals = String::equals;

## 표준 함수형 인터페이스
1. Consumer<T> : T 타입의 인자를 받아 '소비'만 함(반환값 없음)
* Consumer<String> printer = message -> System.out.println(message);
2. Supplier<T> : 아무것도 받지 않고, T 타입의 객체를 '공급' 함
* Supplier<LocalDateTime> timeSupplier = (() -> LocalDateTime.now());
3. Function<T, R> :  T 타입의 인자를 받아, R 타입의 객체로 '변환'하여 반환
* Function<String, Integer> length = str -> str.length();
4. Operator 계열 : 입력 타입과 반환 타입이 같은 Function 계열 UnaryOperator<T> : 동일한 T타입 인자를 1개 받아 같은 T 타입으로 반환
* UnaryOperator<String> toUpper = str -> str.toUpperCase();
5. BinaryOperator<T> : 동일한 T 타입 인자를 2개 받아 같은 T 타입으로 반환
* BinaryOperator<Integer> sumOperator = (num1, num2) -> num1 + num2;
6. Predicate<T> : T 타입의 인자를 받아 검사하고 boolean으로 판단하여 반환
* Predicate<String> isNotEmpty = str -> str != null && !str.isEmpty();

## stream
> 컬렉션에 들어있는 여러 데이터를 조건에 따라 거르고, 바꾸고, 모으는 작업을 읽기 좋게 만들어주는 API
1. count() 조건에 맞는 요소의 개수 세기
* long leeCount = names.stream().filter(name -> name.startsWith("이")).count();
2. anyMatch() 조건에 맞는 요소가 하나라도 있는지 확인
* boolean hasJang = names.stream().anyMatch(name -> name.equals("장보고"));
3. allMatch() 모든 요소가 조건을 만족하는지 확인
* boolean isAllThreeLetters = names.stream().allMatch(name -> name.length() == 3);
