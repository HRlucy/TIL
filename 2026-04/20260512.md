## java File 객체 생성
> 대상 파일이 실제 존재하지 않아도 인스턴스 생성가능
* File file = new File("src/com/kim/section01/test.txt");

## FileInputStream
> File로부터 데이터를 1바이트씩 읽어오는 스트림 주요 대상 : 모든 종류의 파일(이미지, 영상, 텍스트 등)
* stream = new FileInputStream("src/com/kim/section02/testInputStream.txt");
* read() 파일에 기록된 값을 1바이트씩 읽어옴 더이상 읽을 데이터가 없으면 -1을 반환

## FileOutputStream
> 데이터를 1바이트씩 파일에 출력하는 스트림 try-with-resources : try() 소괄호 안에서 자원을 선언하면 try 블럭이 끝날 때(정상이든 예외든) 자동으로 close() 호출
* try (FileOutputStream fout = new FileOutputStream("src/com/kim/section02/testOutputStream.txt")) { } catch (FileNotFoundException e) {} catch (IOException e) {}

## FilReader
> char 단위로 읽기 단, 기본 문자셋을 사용하므로 파일 인코딩과 실행 환경 문자셋이 다르면 깨질 수 있음
* try(FileReader fr = new FileReader("src/com/kim/section02/testReader.txt")) {} catch(FileNotFoundException e) {}

## FileWriter
> 프로그램의 데이터를 1글자 단위 파일로 내보내기 위한 출력 스트림
* try(FileWriter fw = new FileWriter("src/com/kim/section02/testWriter.txt")) {} catch (IOException e) {}

## BufferedWriter / BufferedReader
- 기본 스트림(FileWriter / FileReader)를 감싸서 사용하는 보조 스트림
- 버퍼는 데이터를 잠깐 모아두는 메모리 공간
- 데이터를 바로바로 파일에 쓰거나 읽는 것보다, 버퍼를 거치면 입출력 횟수를 줄일 수 있음
- BufferedReader는 readLine()을 제공하여 텍스트를 한 줄씩 읽기 편함
* try(BufferedWriter bw = new BufferedWriter(new FileWriter("src/com/kim/section03/filterstream/testBuffered.txt"))) { } catch (IOException e) {}

## 형변환 보조스트림(InputStreamReader / OutputStreamWriter)
- byte 기반 스트림을 char 기반 스트림으로 연결할 때 사용
- System.in은 키보드 입력을 바이트 단위로 받는 InputStream
- InputStreamReader는 그 바이트를 문자로 해석하여 Reader로 바꿔줌
- BufferedReader는 Reader를 감싸서 버퍼 기능과 readLine()을 제공

감싸는 순서
1. System.in : 키보드 입력을 받는 바이트 스트림
2. InputStreamReader : 바이트 스트림을 문자 스트림으로 변환
3. BufferedReader : 버퍼 기능과 readLine() 추가
