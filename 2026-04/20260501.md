## 배열(Array)
> 동일한 자료형의 묶음(연속된 메모리 공간에 값을 저장하고 사용하기 위한 용도) 배열은 heap 영역에 new 연산자를 이용하여 할당
int score1 = 80;
int score2 = 90;
int score3 = 40;
int score4 = 70;

int sumOfScores = score1 + score2 + score3 + score4;
double avgOfScores = sumOfScores / 4.0;

## 배열 선언(stack 영역에 배열의 주소를 보관할 수 있는 레퍼런스 변수를 만드는 것)
int[] iarr;
int[] iarr2 = new int[5];
int[] iarr4 = {11, 22, 33, 44, 55};

## 사용자 정의 자료형 사용하기
1. 클래스(설계도)를 만든다. (Member.java)
2. 'new' 연산자를 통해 설계도대로 실제 객체를 메모리에 생성한다.
3. 생성된 객체의 주소값을 담을 변수(참조 변수)를 선언하고, 주소값을 저장한다.
4. 생성된 객체(인스턴스)의 필드(속성)에 값 대입
5. 객체의 필드에 접근할 때는 '.'(참조 연산자)를 사용한다.

## 접근제한자
> 클래스 혹은 클래스의 멤버에 참조 연산자로 접근할 수 있는 범위를 제한하기 위한 키워드
1. (+) public : 모든 패키지에서 접근 허용
2. (#) protected : 동일 패키지에서 접근 허용 (단, 상속 관계에 있는 경우 다른 패키지에서도 접근 가능)
3. (~) default : 동일 패키지 내에서만 접근 허용 (작성하지 않는것이 default)
4. (-) private : 해당 클래스 내부에서만 접근 허용
- 위 네가지 접근제한자는 클래스, 생성자, 클래스의 멤버(필드, 메소드)에 모두 사용 가능 단, 클래스 선언 시 사용하는 접근제한자는 public과 default만 사용 가능

## 캡슐화
> 유지보수성을 증가시키기 위해 필드의 직접 접근을 제한하고 public 메소드(getter, setter)를 이용해 접근하여 사용할 수 있도록 만든 기술 클래스 작성 시 특별한 목적이 아닌 이상 캡슐화가 기본 원칙으로 사용
1. Getter(접근자) : 내부 필드의 값을 외부로 읽어서(Get) 전달(반환)하는 역할을 하는 메소드(읽기 전용)
2. Setter(변경자) : 외부에서 전달된 값을 받아, 내부 필드의 값을 설정(Set) 또는 변경하는 역할을 하는 메소드
