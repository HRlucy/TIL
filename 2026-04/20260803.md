# TIL — Linux, Ubuntu, Vim, Docker 기초 요약

## 1. Linux와 Ubuntu

Linux는 엄밀히 말하면 운영체제의 핵심 기능을 담당하는 **커널**이다. Ubuntu는 Linux 커널을 기반으로 만들어진 Linux 배포판 중 하나이다.

VirtualBox를 사용하면 기존 운영체제를 변경하지 않고도 컴퓨터 안에 Ubuntu 가상 머신을 만들어 실습할 수 있다.

---

## 2. 터미널과 Shell

터미널은 사용자가 명령어를 입력하고 실행 결과를 확인하는 프로그램이다.

Shell은 터미널에 입력된 명령어를 해석하여 운영체제에 전달하는 프로그램이다.

대표적인 Shell에는 다음과 같은 종류가 있다.

* `sh`
* `bash`
* `zsh`

---

## 3. 터미널 에디터

터미널에서는 Nano, vi, Vim과 같은 텍스트 에디터를 사용할 수 있다.

* Nano는 사용법이 단순해 입문자에게 적합하다.
* vi는 Linux 서버에 기본 설치된 경우가 많다.
* Vim은 vi의 확장판으로 문법 강조, 검색, 자동 완성, 플러그인 등의 기능을 지원한다.

Vim에서 자주 사용하는 명령은 다음과 같다.

```text
i       입력 모드로 전환
Esc     일반 모드로 전환
:w      저장
:q      종료
:wq     저장 후 종료
:q!     저장하지 않고 종료
```

## 4. apt 패키지 관리

`apt`는 Ubuntu에서 프로그램과 패키지를 설치하고 관리할 때 사용하는 도구이다.

```bash
sudo apt update
sudo apt install vim
sudo apt remove vim
```

`apt update`는 프로그램을 직접 업데이트하는 명령이 아니라, 설치 가능한 패키지 목록을 갱신하는 명령이다.

---

## 5. 경로 표현

절대 경로는 루트 디렉터리 `/`부터 시작하는 전체 경로이다.

```bash
/home/user/project/file.txt
```

상대 경로는 현재 디렉터리를 기준으로 나타낸 경로이다.

```bash
./file.txt
../project/file.txt
```

주요 경로 기호는 다음과 같다.

| 기호   | 의미             |
| ---- | -------------- |
| `/`  | 루트 디렉터리        |
| `.`  | 현재 디렉터리        |
| `..` | 상위 디렉터리        |
| `~`  | 현재 사용자의 홈 디렉터리 |

## 6. 기본 Linux 명령어

```bash
pwd
ls
cd
mkdir
touch
cat
cp
mv
rm
find
which
```

* `pwd`: 현재 위치 확인
* `ls`: 파일 목록 확인
* `cd`: 디렉터리 이동
* `mkdir`: 디렉터리 생성
* `touch`: 빈 파일 생성
* `cat`: 파일 내용 출력
* `cp`: 파일 복사
* `mv`: 파일 이동 또는 이름 변경
* `rm`: 파일 또는 디렉터리 삭제
* `find`: 파일 검색
* `which`: 명령어 실행 경로 확인

`rm`은 파일을 휴지통으로 보내지 않고 즉시 삭제할 수 있으므로 사용 전에 경로를 반드시 확인해야 한다.

## 7. 리디렉션과 grep

리디렉션은 명령어의 실행 결과를 파일에 저장하는 기능이다.

```bash
echo "hello" > memo.txt
echo "world" >> memo.txt
```

* `>`: 기존 내용을 덮어쓰기
* `>>`: 기존 내용 뒤에 이어쓰기
* `<`: 파일 내용을 입력으로 사용

`grep`은 파일이나 명령어 출력에서 특정 문자열 또는 패턴을 검색할 때 사용한다.

```bash
grep -n "error" app.log
docker ps -a | grep "ubuntu"
```

## 8. Docker 이미지와 컨테이너

Docker는 애플리케이션과 실행에 필요한 환경을 이미지로 묶고, 이를 컨테이너라는 격리된 환경에서 실행하도록 도와주는 도구이다.

* 이미지: 애플리케이션 실행 환경을 담은 템플릿
* 컨테이너: 이미지를 기반으로 실제 실행된 프로세스 환경

하나의 이미지로 여러 개의 컨테이너를 생성할 수 있다.

---

## 9. Docker 기본 명령어

```bash
docker pull ubuntu
docker run -it --name ubuntu_test2 ubuntu bash
docker ps
docker ps -a
docker start ubuntu_test2
docker exec -it ubuntu_test2 bash
docker stop ubuntu_test2
docker rm ubuntu_test2
docker container prune
```

* `docker pull`: 이미지 내려받기
* `docker run`: 새로운 컨테이너 생성 및 실행
* `docker ps`: 실행 중인 컨테이너 확인
* `docker ps -a`: 전체 컨테이너 확인
* `docker start`: 중지된 기존 컨테이너 시작
* `docker exec`: 실행 중인 컨테이너에서 새로운 명령 또는 Shell 실행
* `docker stop`: 컨테이너 중지
* `docker rm`: 컨테이너 삭제
* `docker container prune`: 중지된 컨테이너 일괄 삭제

---

## 10. 컨테이너에서 빠져나오기

`docker attach`로 연결한 상태에서 다음 키를 순서대로 입력하면 컨테이너를 계속 실행한 채 연결만 해제할 수 있다.

```text
Ctrl + P
Ctrl + Q
```

다음 명령이나 키를 사용하면 현재 Shell이 종료된다.

```text
exit
Ctrl + D
```

컨테이너의 주 프로세스가 해당 Shell이라면 Shell이 종료되면서 컨테이너도 중지될 수 있다.

Linux 명령어와 터미널 사용법은 서버 환경을 다루기 위한 기본 지식이다. Docker는 애플리케이션 실행 환경을 이미지로 관리하고, 컨테이너 단위로 일관되게 실행할 수 있도록 도와준다.
